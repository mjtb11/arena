## مسائل یافته‌شده و اصلاح‌شده در بازبینی فریم‌ها
1. **منافذ آلفا در نقاشی RGBA** (ImageDraw به‌جای blend، پیکسل را جایگزین می‌کند) → پلی‌گون نقشه، گردوغبار، ستاره‌ها، پرتوها و سایهٔ صندروی به لایه‌های جدا منتقل شدند (Contact Sheet A قبل/بعد).
2. **لک‌های بافت کاغذ** روی پس‌زمینه‌های تیره → نسخهٔ high-pass بدون لک (`paper_hp`) ساخته شد.
3. **هابهٔ ناخواستهٔ کلاه** از ابتدای بیت ۸: `eback(0)` مقدار 2.2e-16 برمی‌گرداند و شرط `hk>0` همیشه درست بود → تابع اصلاح شد.
4. **برخورد چیپ‌ها با کاراکتر/کلاه** در بیت ۸ و عنوان بیت ۱ → جانمایی مجدد.
5. **خوانایی شمشیرهای متقاطع** بیت ۴ → اندازه/زاویه بازطراحی شد.
6. **کدری بیت ۷** → پس‌زمینه به گرادیان آبی شفاف + پردهٔ کاغذی سبک تغییر کرد.
7. **نوار زیرنویس ثابت و پهن** → عرض تطبیقی با متن.

## محدودیت محیط و راه‌حل
- دانلود Chrome Headless Shell برای `remotion render` در این سندباکس مسدود است (میزبان `remotion.media` در فهرست مجاز نیست) و Chromium جایگزین هم در این محیط اجرا نشد.
- بنابراین: **کامپوزیشن کامل و قابل‌ویرایش Remotion** در `video/` تحویل شده (type-check تمیز) و رندر نهایی داخل سندباکس با **رندرکنندهٔ آینهٔ همان استوری‌برد** (`tools/render_mirror.py`، Pillow + FFmpeg) تولید شد تا همهٔ خروجی‌ها قابل تحویل و بازبینی باشند.
- روی ماشین خودتان: `cd video && npm install && npm run render` → رندر اصلی Remotion با همان دارایی‌ها و همان تایم‌لاین.
