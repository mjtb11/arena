# فونت‌ها و رنگ‌ها

## فونت
- **Vazirmatn** (فارسی/عربی + لاتین) — خوانا، رسمی و متناسب با لحن تاریخی؛ بارگذاری محلی (بدون شبکه هنگام رندر).
  - Remotion: `src/theme.ts` → `loadFont()` روی `staticFile('fonts/vazirmatn-*-normal.woff2')`
  - رندر Pillow: `video/public/fonts/ttf/Vazirmatn-*.ttf` + شکل‌دهی با `arabic-reshaper` + `python-bidi`
- وزن‌ها:
  - عنوان‌ها و مُهرها: **900 / 800**
  - برچسب‌ها (Chip): **700**
  - زیرنویس: **500** (سایز 46px، نوار تیرهٔ نیمه‌شفاف با نوار طلایی کناری، حداکثر ۲ خط)
- جهت متن: RTL کامل (dir=rtl / bidi)

## قواعد گریدینگ
- کاهش اشباع تصاویر واقعی (≤ 0.55)، تاری ملایم برای دوردست‌ها
- وینیت ملایم + گرین کاغذی بسیار کم (high-pass) برای یکدستی سبک
- پس‌زمینه هرگز از کاراکتر پیشی نمی‌گیرد (darken 0.34–0.5 روی پس‌زمینه‌ها)
